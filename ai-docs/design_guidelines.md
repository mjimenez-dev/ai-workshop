# UI/UX Style Guide: E-Commerce Gaming Platform

## General Overview of the Design System

This e-commerce gaming platform employs a clean, modern design system built around accessibility, visual hierarchy, and user-centered shopping experiences. The design follows contemporary e-commerce patterns with a focus on product discovery and conversion optimization.

### Design Philosophy

- **Minimalist Approach**: Clean layouts with ample whitespace to highlight products
- **Conversion-Focused**: Strategic use of red accent color for CTAs and promotional elements
- **Accessibility-First**: High contrast ratios and clear visual hierarchy
- **Mobile-Responsive**: Flexible grid systems that adapt across devices
- **Trust-Building**: Professional typography and consistent spacing to establish credibility


### Visual Hierarchy Principles

- Primary actions use the signature red color (`#DB4444`)
- Secondary actions maintain neutral tones
- Product imagery is given prominence through generous spacing
- Information architecture follows F-pattern reading behavior


---

## Color Palette

### Primary Colors

- **Brand Red**: `#DB4444` - Primary CTAs, discounts, active states
- **Pure Black**: `#000000` - Primary text, navigation, footer background
- **Pure White**: `#FFFFFF` - Main background, card backgrounds


### Secondary Colors

- **Light Gray**: `#F5F5F5` - Product image backgrounds, input fields
- **Medium Gray**: `#D9D9D9` - Borders, dividers, inactive elements
- **Off-White**: `#FAFAFA` - Subtle background variations


### Accent Colors

- **Success Green**: `#00FF66` - Stock status, success messages
- **Warning Orange**: `#FFAD33` - Star ratings, warning states


### Semantic Colors

- **Text Primary**: `#000000` (100% opacity)
- **Text Secondary**: `#000000` (60% opacity)
- **Text Disabled**: `#000000` (30% opacity)


---

## Typography System

### Font Family

- **Primary**: System font stack (likely Inter or similar sans-serif)
- **Fallback**: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif


### Font Scales

- **Heading Large**: 32px / 2rem - Main page titles
- **Heading Medium**: 24px / 1.5rem - Section headers
- **Heading Small**: 20px / 1.25rem - Product titles
- **Body Large**: 16px / 1rem - Primary body text
- **Body Medium**: 14px / 0.875rem - Secondary text, labels
- **Body Small**: 12px / 0.75rem - Captions, metadata


### Font Weights

- **Bold**: 700 - Primary headings, prices
- **Semibold**: 600 - Secondary headings, labels
- **Medium**: 500 - Navigation items, buttons
- **Regular**: 400 - Body text, descriptions


---

## Spacing and Grid System

### Base Unit

- **Base**: 4px (0.25rem)
- **Scale**: 4px, 8px, 12px, 16px, 24px, 32px, 48px, 64px


### Layout Grid

- **Container Max Width**: 1200px
- **Gutter**: 16px (mobile), 24px (tablet), 32px (desktop)
- **Columns**: 12-column grid system
- **Breakpoints**:

- Mobile: 320px - 767px
- Tablet: 768px - 1023px
- Desktop: 1024px+





### Component Spacing

- **Card Padding**: 16px - 32px
- **Button Padding**: 12px horizontal, 8px vertical
- **Section Margins**: 64px - 96px between major sections

## Font and Background Colors by UI Section

### Header/Navigation

- **Background**: `#FFFFFF` (Pure White)
- **Primary Text**: `#000000` (Navigation links, logo)
- **Interactive Elements**: `#DB4444` on hover
- **Search Input**: `#F5F5F5` background, `#000000` text
- **Borders**: `#D9D9D9`


### Product Grid Section

- **Background**: `#FFFFFF` (Main background)
- **Section Headers**: `#000000` (Bold, 24px)
- **Product Names**: `#000000` (Medium, 16px)
- **Prices**: `#DB4444` (Primary price), `#000000` with 50% opacity (crossed-out price)
- **Card Backgrounds**: `#F5F5F5` (Product image areas)
- **Discount Badges**: `#FFFFFF` text on `#DB4444` background


### Product Detail Section

- **Background**: `#FFFFFF`
- **Product Title**: `#000000` (Semibold, 24px)
- **Price**: `#000000` (Bold, 24px)
- **Body Text**: `#000000` (Regular, 16px)
- **Labels**: `#000000` (Medium, 14px)
- **Stock Status**: `#00FF66` (Success green)
- **Rating Stars**: `#FFAD33` (filled), `#D9D9D9` (empty)
- **Size/Color Options**: `#000000` text on `#FFFFFF` with `#D9D9D9` borders
- **Active Selection**: `#FFFFFF` text on `#DB4444` background


### Call-to-Action Elements

- **Primary Buttons**: `#FFFFFF` text on `#DB4444` background
- **Secondary Buttons**: `#000000` text on `#FFFFFF` with `#D9D9D9` border
- **Add to Cart (Hover)**: `#FFFFFF` text on `#000000` background


### Footer

- **Background**: `#000000` (Pure Black)
- **Primary Text**: `#FFFFFF` (Headings, important links)
- **Secondary Text**: `#FFFFFF` with 70% opacity (Body text, descriptions)
- **Copyright Text**: `#FFFFFF` with 50% opacity
- **Input Fields**: Transparent background with `#FFFFFF` 30% opacity border
- **Subscribe Button**: `#000000` text on `#FFFFFF` background


### Interactive States

- **Hover States**:

- Links: `#DB4444`
- Buttons: 90% opacity of base color
- Cards: Subtle shadow elevation



- **Focus States**: 2px `#DB4444` outline
- **Disabled States**: 30% opacity of base colors
- **Active States**: `#DB4444` for selections and current page indicators


### Notification Elements

- **Success Messages**: `#00FF66` text or background
- **Error Messages**: `#DB4444` text or background
- **Warning Messages**: `#FFAD33` text or background
- **Info Messages**: `#000000` text with `#F5F5F5` background


This color system ensures consistent visual hierarchy while maintaining excellent accessibility standards across all interface sections.
